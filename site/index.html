✦VESPERA

A game store you run yourself — accounts, credits, a store and library, game uploads, reviews, an admin panel and Discord-style profiles.

⬇ Download for Windows ❖ Download the source

Vespera-Windows.zip · about 1.8 MB · rebuilt automatically from the latest code

1

Unzip it

Right-click the downloaded zip and choose Extract All.

2

Run Vespera.exe

Double-click it. Windows may warn about an unknown publisher — choose More info, then Run anyway.

3

It opens in your browser

Vespera runs at localhost:8080. The first account you create becomes the admin.

Good to know

Vespera is a desktop app, not a website. It starts a small server on your own machine, so this page can only hand you the download — keep the Vespera window open while you use it, and everything you create is saved in the data folder next to the .exe.

On macOS or Linux, grab the source above and run make run (needs g++, make and zlib1g-dev). To put Vespera online for other people on your own server with HTTPS, see the README.
